# CancerScope: Local Pathology Triage on ASUS GX10

Triage CAMELYON16 lymph-node slides locally: UNI2-h tile features → PCam-trained classifier → heatmap → urgency-ranked queue → LLM-drafted report. Full brief: [CLAUDE.md](CLAUDE.md).

## Setup
```bash
git clone git@github.com:<you>/CancerScope.git && cd CancerScope
bash setup.sh                 # venv (.venv), openslide, pip packages
source .venv/bin/activate
hf auth login                 # token with access to the gated MahmoodLab models
bash fetch_data.sh            # UNI2-h + PCam + demo slides/XML (resumable; or one part: uni2h|models|pcam|slides)
```
Models and data are never committed (licenses forbid redistributing weights). Layout, matching `config.py`:
```
models/pretrained/{UNI2-h,UNI,CONCH,prov-gigapath}/
data/pcam/data/*.parquet
data/camelyon16/{slides/*.tif, annotations/*.xml}
```

## Run
```bash
python -m pipeline.make_sample_outputs        # fake outputs in outputs/_sample/ (app dev)
python -m pipeline.extract_pcam_features      # Phase A: PCam -> UNI2-h features
python -m pipeline.train_classifier           # Phase A: -> models/trained/tumor_classifier.pt
python -m pipeline.process_slide tumor_091    # Phase B: one slide -> outputs/tumor_091/
python -m pipeline.run_batch                  # all slides, live index.json updates
python -m eval.compare_annotations            # accuracy vs. PCam test + CAMELYON16 outlines
CANCERSCOPE_OUTPUTS=outputs/_sample python -m app.server   # app on sample data
```
Always run as modules from the repo root (`python -m ...`) so `import config` works.

## Output contract
Per slide, `outputs/<slide_id>/`: `heatmap.png`, `heatmap.npy`, `thumbnail.png`, `metrics.json`, `report.md`. Schema v1 is in CLAUDE.md; `outputs/_sample/` has real examples generated by the same code as the pipeline (`pipeline/slide_metrics.py`).

**Additive fields** (beyond the brief's schema; nothing removed):
- `category`: `Macrometastasis` / `Micrometastasis` / `Isolated tumor cells` / `Negative`, for the badge.
- `largest_region_extent_mm`: longest bbox side of the largest region; drives the category.
- `heatmap_width`, `heatmap_height`: heatmap grid size in pixels.
- `outputs/<slide_id>/annotation.json` (tumor slides only, written by `eval.compare_annotations`): pathologist outline as `{"tumor": [[[x, y], ...], ...], "exclusion": [...]}` in level-0 px, for drawing over the slide in the viewer (demo step 4).
- `outputs/eval/<slide_id>_compare.png`: pathologist outline | our heatmap | overlay, for the evidence slide.

**Heatmap alignment.** The grid is `ceil(slide_w / ds) x ceil(slide_h / ds)`, so it overhangs the right and bottom slide edges by less than one cell. Place the overlay with level-0 width `heatmap_width * heatmap_downsample` (not `slide_width_px`); in OpenSeadragon viewport units that is `heatmap_width * heatmap_downsample / slide_width_px`. `heatmap.npy` is float32 tumor probability, 0 outside tissue.

**index.json**
```json
{"schema_version": 1, "slides": [
  {"slide_id": "tumor_091", "filename": "tumor_091.tif", "status": "done",
   "urgency_score": 9.4, "category": "Macrometastasis", "gb_processed": 0.81,
   "output_path": "tumor_091"}]}
```
`status` is `queued`, `processing`, `done`, or `error` (processing failed; see the pipeline log). `urgency_score` and `category` are `null` until `status == "done"`. `output_path` is relative to the outputs dir. Counter = sum of `gb_processed`.

## Rules (record final tuned values here)
- Tumor tile: probability > `0.5` (`config.TUMOR_THRESHOLD`).
- Regions: threshold → 3x3 closing → 8-connected components; area counts only above-threshold tiles.
- `tumor_detected`: any region ≥ `0.2 mm²` with max confidence > 0.5.
- Urgency: category by the largest region's longest extent (> 2 mm macro, > 0.2 mm micro, else ITC), then within the band by max confidence mapped from (0.5, 1] → [0, 1]. Negative = 0.
